# brand.synaptec.sk

Verejná webová verzia brand a dizajn manuálu Synaptec. Statická stránka pre GitHub Pages (repozitár synaptec-sk-brand/brand).

- Verzia: pozri `version.json` a `CHANGELOG.md` (číslovanie M.N.W – M.N manuál, W web).
- `index.html` – celý manuál · `files/` – súbory na stiahnutie · `fonts/` – písma pre web
- `CNAME` (brand.synaptec.sk) a `.nojekyll` musia zostať v koreni repozitára.
